# ChoreQuest 🏆

A fun family app where kids complete chores, earn coins, and unlock awesome rewards — all with satisfying animations!

## Features

- 👶 **Multiple Kids** – Add every child to the family; switch between them with a tap
- ✅ **Chore Tracking** – Six starter chores included; add, remove, and customise your own with emoji icons and coin rewards (1–50 🪙)
- 🎯 **Savings Goals** – Each kid can set personal goals (a toy, an outing, anything!) and watch their progress bar fill up
- 🏆 **Claim Rewards** – When a kid earns enough coins, the goal glows and they can claim it — deducting coins from their balance
- 🎉 **Celebration Animations** – Confetti bursts and a pop-up card on every chore completion
- 💾 **Persistent Storage** – All data lives in `localStorage` — no account or server needed

## Getting Started

```bash
npm install
npm run dev
```

Then open <http://localhost:5173> in your browser.

## Tech Stack

- **React 19** with TypeScript
- **Vite** for fast dev & build
- Pure CSS animations (no external animation libraries)
- `localStorage` for client-side persistence
